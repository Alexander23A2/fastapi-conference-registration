# Система реєстрації учасників конференції (FastAPI Conference)

Вебзастосунок з архітектурою Server-Side Rendering (SSR) для реєстрації та управління списками учасників наукової конференції. Проєкт розроблено в рамках виробничої практики. Фокус системи — ізоляція даних та безпека доступу.

##  Технологічний стек

* **Backend:** Python, FastAPI
* **Database:** SQLite, SQLAlchemy (ORM)
* **Validation:** Pydantic v2
* **Security:** bcrypt (хешування паролів), PyJWT (авторизація через HTTP-only cookies)
* **Frontend:** Jinja2 Templates, Bootstrap 5

##  Структура проєкту

* `main.py` — головний серверний файл та логіка маршрутизації HTTP-запитів.
* `models.py` / `schemas.py` — архітектура таблиць бази даних та Pydantic-схеми.
* `auth.py` — криптографічний модуль безпеки.
* `database.py` — підключення до реляційної СУБД SQLite.
* `templates/` — HTML-шаблони користувацького інтерфейсу.

##  Інструкція із запуску (Локальне розгортання)

1. Клонувати репозиторій:
```bash
git clone https://github.com/Alexander23A2/fastapi-conference-registration.git
cd fastapi-conference-registration
```

2. Створити та активувати віртуальне середовище:
```bash
python -m venv venv
# Активація для Windows:
.\venv\Scripts\Activate.ps1
```

3. Встановити залежності проєкту:
```bash
pip install -r requirements.txt
```

4. Запустити локальний сервер:
```bash
python -m uvicorn main:app --reload
```
Застосунок стане доступним за адресою: `http://127.0.0.1:8000`

##  Реалізована схема безпеки

* **Захист паролів:** Чисті паролі не зберігаються в базі даних. Використовується незворотне хешування алгоритмом `bcrypt` із додаванням криптографічної солі.
* **Безстанова авторизація (Stateless):** Доступ до закритих маршрутів реалізовано через JWT. Токен передається в ізольованих `HTTP-only cookies`, що запобігає атакам типу XSS.
* **Row-Level Security:** На сторінці дашборду доступ до модифікації даних жорстко обмежений. Сервер динамічно перевіряє власника токена і дозволяє редагувати виключно власний запис у базі даних.
